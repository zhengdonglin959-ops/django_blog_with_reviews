# Учебный блог на Django

Учебный проект по дисциплине «Технологии создания интернет-приложений».
Содержит:

- три страницы блога (главная, о блоге, страница поста) на шаблонах с наследованием;
- страницу **«Книга отзывов»** с формой добавления отзыва;
- модель `Review` (ФИО, email, текст отзыва, флаг «Проверено»);
- модель зарегистрирована в админ-панели, можно отмечать отзывы как проверенные;
- отзывы отображаются на странице только после того, как администратор поставит
  галочку «Проверено».

---

## Установка и запуск с нуля

Предполагается, что на компьютере уже установлен интерпретатор Python 3.10+.

### 1. Клонировать репозиторий и перейти в папку проекта

```bash
git clone <ссылка-на-репозиторий>.git
cd mysite_blog
```

### 2. Создать и активировать виртуальное окружение

**Windows (cmd / PowerShell):**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Выполнить миграции базы данных

```bash
python manage.py migrate
```

### 5. Создать суперпользователя для доступа в админ-панель

```bash
python manage.py createsuperuser
```

После запуска команды введите имя пользователя, email и пароль.

### 6. Запустить сервер разработки

```bash
python manage.py runserver
```

Откройте в браузере:

- Главная блога: http://127.0.0.1:8000/
- Книга отзывов: http://127.0.0.1:8000/reviews/
- Панель администратора: http://127.0.0.1:8000/admin/

---

## Как работает модерация отзывов

1. Посетитель заполняет форму на странице `/reviews/` и отправляет отзыв.
2. Новый отзыв сохраняется в базе данных с флагом `Проверено = False` и
   **не отображается** на сайте.
3. Администратор заходит в `/admin/`, открывает раздел «Отзывы» и ставит
   галочку «Проверено» напротив отзыва.
4. После этого отзыв появляется на странице «Книга отзывов».
